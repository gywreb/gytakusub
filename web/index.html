Set up chapter links

Browsers don't let a web page read other websites. So chapter links go through a small program called a fetcher, running on a free Cloudflare account. It opens the chapter and passes the pages to this app. Screenshot mode works without it.

Got a connection link?

Someone who already has a fetcher can send you one. Paste it here.

Or set up your own fetcher

Free. About 10 minutes, once. Easiest on a computer; afterwards you connect your phone with a link. Tap a grey value to copy it.

  1. You need both. Skip any you already have.

    1. GitHub (where your copy of the fetcher lives): github.com/signup ↗
    2. Cloudflare (where it runs): dash.cloudflare.com/sign-up ↗. Confirm your email.

  2. Only someone with this key can use your fetcher. The app remembers it; you'll paste it into Cloudflare in step 5.

    —

    1. Open github.com/gywreb/gytakusub ↗ while signed in.
    2. Click Fork (top right), then Create fork.

    You now have your own copy, also named . Cloudflare can only deploy from a repository in your own account, which is why this copy is needed.

    1. Open dash.cloudflare.com ↗, then Workers & Pages → Create application → GitHub.
    2. If asked, allow Cloudflare to see your GitHub repositories. Then select your .
    3. Set these four fields; leave everything else as it is:
      • Project / Worker name: . Exactly this, or the build fails.
      • Root directory: . It may be under Advanced settings.
      • Build command: leave empty.
      • Deploy command:
    4. Click Save and Deploy and wait about a minute until it says it's deployed.

    If the build fails, check those four fields under the Worker's Settings → Build, correct them, and deploy again.

    1. On the Worker's page: Settings → Variables and Secrets → Add.
    2. Type: Secret. Variable name: . Value: your key ().
    3. Click Deploy.
    4. Copy the Worker's address from its page. It looks like https://gytakusub.your-name.workers.dev.

Update your fetcher later

If the app says your fetcher is out of date: open your copy on GitHub and click Sync fork → Update branch. Cloudflare redeploys by itself within a minute. Then Connect again.
