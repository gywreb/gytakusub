Set up chapter links

Browsers don't let a web page read other websites. So chapter links go through a small program called a fetcher, running on a free Cloudflare account. It opens the chapter and passes the pages to this app. Screenshot mode works without it.

Got a connection link?

Someone who already has a fetcher can send you one. Paste it here.

Or set up your own fetcher

Free, about 10 minutes, once. You need a free GitHub account and a free Cloudflare account. A computer is easiest; afterwards you can connect your phone with a link.

  1. Create your access key

    Only someone with this key can use your fetcher. You'll paste it in step 4.

    —

  2. Copy the fetcher to your GitHub

    1. Open github.com/gywreb/gytakusub ↗ and sign in (or create a free account).
    2. Click Fork (top right), then Create fork. You now have your own copy, also called gytakusub.

  3. Deploy it on Cloudflare

    1. Open dash.cloudflare.com ↗ and sign in (or create a free account and confirm your email).
    2. Go to Workers & Pages → Create application → GitHub. If asked, allow Cloudflare to see your GitHub repositories.
    3. Select your copy, gytakusub.
    4. Fill in the settings. Anything not listed here, leave as it is:
      • Project / Worker name: gytakusub. It must be exactly this, or the build fails.
      • Root directory: fetcher (it may be under Advanced settings).
      • Build command: leave empty.
      • Deploy command: npx wrangler deploy.
    5. Click Save and Deploy and wait for it to finish (about a minute).

  4. Give the fetcher your key

    1. On the Worker's page, open Settings → Variables and Secrets → Add.
    2. Type: Secret. Variable name: GYT_KEY. Value: your key from step 1.
    3. Click Deploy.
    4. Copy the Worker's address from its page. It looks like https://gytakusub.your-name.workers.dev.

  5. Connect

Update your fetcher later

If the app says your fetcher is out of date: open your gytakusub copy on GitHub, click Sync fork → Update branch. Cloudflare redeploys by itself within a minute. Then tap Connect again.

If a Cloudflare screen looks different, see Cloudflare's own help: deploying from GitHub · adding a secret. These steps were last checked against those pages on .
