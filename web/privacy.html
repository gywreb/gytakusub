Gytakusub — Privacy Policy

Effective 8 November 2026. Applies to the Gytakusub browser extension and the Gytakusub web app (gywreb.github.io/gytakusub).

Summary

Gytakusub has no server and no account system. The developer never receives your data. The only data that leaves your device is sent, by your browser, directly to Anthropic's Claude API using your own API key, in order to translate the image you asked to translate.

What is processed, and where

  • Page images. When you translate an image (by hovering and clicking, pressing a shortcut, enabling auto-translate on a site you chose, or pasting a screenshot into the web app), a downscaled copy of that image is sent to api.anthropic.com so the model can read and translate the text. Anthropic's handling of API inputs is governed by Anthropic's commercial terms and privacy policy. The developer of Gytakusub has no access to these requests.
  • Your API key. Stored in your browser's extension storage (device-local by default; optionally in your browser's sync storage if you turn that on) or, in the web app, in the browser's localStorage. It is sent only to api.anthropic.com as the authentication header.
  • Settings, glossary, and chapter context. Your model choice, target language, glossary, list of enabled sites, and the names and recent translated lines used for consistency are stored locally in the browser (and in browser sync storage for settings, if your browser syncs). Chapter context is per tab and discarded when the tab closes.
  • Translation cache. Translations are cached in browser session storage so re-opening a page does not cost tokens; the cache is cleared when the browser closes.

What is not collected

  • No analytics, telemetry, crash reporting, or advertising identifiers.
  • No browsing history. The extension runs only on sites you enable, or on a page where you explicitly invoke it from the toolbar or a shortcut.
  • No images, translations, or keys are ever sent to the developer or to any party other than Anthropic.

Optional image proxy (web app only)

If you deploy and configure your own Cloudflare Worker from worker.js, image bytes for chapter pages pass through your worker. The developer does not operate any proxy.

Permissions (extension)

  • storage — save your settings and key locally.
  • activeTab, scripting — inject the translator into the current tab when you ask, and register it on sites you enable.
  • Host permission for all sites — required to fetch the page images you are viewing from whichever image server the site uses, so they can be read and translated. Gytakusub does not read or modify page content other than the images you translate.

Your control

Remove the API key or any setting from the extension's Options page or the web app's Settings; uninstalling the extension or clearing site data for the web app deletes everything stored locally. There is nothing to delete on the developer's side because nothing is held there.

Changes and contact

Changes to this policy are published in the project repository. Questions: open an issue on the repository.
