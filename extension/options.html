Claude API

Gytakusub sends pages to Claude with your own key.

Create one at platform.claude.com → Settings → API keys. Usage is billed to that Console account, separately from a Claude subscription (Max, Ultra and Team plans include monthly API credits).

Translation

Names and terms the model must use exactly. Names it discovers on its own are remembered per tab automatically.

Sites

One hostname per line. The easiest way to add a site: open it and use the switches in the toolbar popup.

The hover button and keyboard shortcuts work only here. Everywhere else Gytakusub stays dormant until you use the toolbar button or the shortcut.

Each page that scrolls into view is sent to Claude automatically, so only add sites where you want to spend tokens. These count as enabled too.

Gytakusub stays off on these sites and their subdomains.

Lettering & speed

Leave empty for the bundled lettering font (Comic Neue Bold), or name any font installed on this device, e.g. "Bangers".

Troubleshooting

Translation cacheTranslated pages, the names found per tab and your edited lines are kept until the browser closes. Clear them to translate pages afresh.
